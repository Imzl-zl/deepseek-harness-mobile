# .agents/notes 规则

本目录记录代码装不下的「为什么」:当初为什么这么定、否定过哪些方案、代价是什么。
现状事实属于 `docs/`,事故记录属于 `docs/postmortem/`,本目录只管因果取舍。

## 不变量

- 状态由目录位置决定:`proposed/` 待评审、`implemented/` 已落地、`rejected/` 已否决、`archived/` 被取代。
- 文件名:`YYYY-MM-DD-<kebab-slug>.md`,日期取决定作出或落地的日期。
- 严禁创建 `INDEX.md`、`README.md` 或任何"每篇笔记都要改一行"的总索引。
- `implemented/` 随代码更新;它只写已经发生的事实,禁止 `## Proposal` / `## 计划` / `## TODO` 类标题。
- `archived/` 永久冻结:封起来不许改。
- 已经发生的决定不能删:被取代时旧篇结论不改,标注被谁取代后移入 `archived/`;新篇引用旧篇并写清代价。
- 代码与笔记同批提交;被约束的代码入口留一行注释回指本篇。

## 写作方法

格式、非平凡判定表、四格写法与验收清单见 `decision-notes` 技能;本目录不复制它们,避免两处漂移。
