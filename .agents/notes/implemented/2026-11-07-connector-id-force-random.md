# 连接器标识：`local` 一律强制迁移成随机值

Status: implemented

## 背景

2026-11-06 生产：`dsh.0t0.me` 上两个账号的电脑都用旧默认 `local`，令牌表出现两条指向
同一 `connectorId` 的记录；中转重启时按启动校验拒绝启动，停了 4 分钟
（`relay/src/token-table.ts` 的 `byConnector` 唯一性）。根因是 `connector/src/index.ts`
把字面量 `local` 作为首装默认值写进存储，而这个值同时是**中转控制面的连接器身份**
（`?id=`），在共用中转上必然跨租户相撞。

前一版实现（`archived/2026-11-06-connector-id-random-default.md`）为了不让老用户重扫，
只迁移"没有已配对设备"的 `local`，有配对的保留并告警。2026-11-07 用户拍板：
**现在用户很少、还没宣发，不要留兼容尾巴，直接全部换新的。**

## Decision

1. `pcId` 的模型定死为：**一台电脑一个随机不透明标识** `pc-` + 12 字节 base64url，
   首装生成、写进 `meta.connectorId`、之后一直读它；`local` 只作为历史值被识别并迁移。
2. `resolveConnectorId` 对 `''` 和 `local` 都生成新值，**不再看设备表有没有配对**。
3. 迁移时**清掉旧的连接器令牌**（它一定绑在 `local` 上，新 id 对不上）。清掉后：
   - 中转 `connectorAuth: open` → 下次启动自助兑换一张新令牌；
   - `required` → 如实报"没有令牌"，由管理员在管理台重签。
4. 已配对手机**必须重新扫码**：手机存着配对时的 `pcId`，握手 transcript 对不上。
   这是有意接受的代价，不写兼容分支。

## 架构口径

- `pcId` 是**路由标签**，不是加密身份；手机真正钉的是 `pcSignPubHex`（配对时写进凭据）。
  换 `pcId` 不改密钥，只让旧配对作废 —— 语义就是"这台电脑换了个身份"。
- `pcId` 之所以不能像主机名一样随便改，是因为它进了握手 transcript
  （`docs/subsystems/remote-channel.md` §12.1）；这是协议现状，不是本次新增的限制。
- 中转令牌与 `pcId` 是两条独立的凭据：令牌绑定 `?id=`，换 `pcId` 必须重签/重绑。
  连接器端迁移时清旧令牌，中转端的旧条目按 `docs/cookbook/relay-on-a-server.md` §6.6
  清理（否则重启时两条 `local` 仍会触发启动校验）。

## Alternatives considered

1. **新装随机、有配对的老装保留 `local`**（前一版，已 archived）
   - 最强理由：老用户完全不用重扫。
   - 为何被否：用户 2026-11-07 明确"没多少用户，直接换新的"；留着 `local` 就是把
     一个已知的跨租户冲突永久留在架构里。
2. **`pcId` 由 `pcSignPubHex` 派生**
   - 最强理由：确定性、可重算、不依赖随机数存储。
   - 为何被否：`pcId` 只是路由标签，派生不增加唯一性；反而要求 `open-store` 前先加载
     身份（当前顺序是 store 先于 identity），并让"换密钥"和"换标签"永久绑死。随机值
     已经足够唯一，且不引入装配顺序耦合。
3. **中转按账号隔离 connectorId（`(userId, connectorId)` 复合键）**
   - 最强理由：老装不用改、手机不用重扫，从根上消除耦合。
   - 为何被否（本轮）：这是 relay 的结构性改动，涉及控制面/名册/额度/通道的安全边界
     重审；在"用户少、可直接换新"的前提下，代价大于收益。若以后出现不能重扫的存量，
     这条仍是正确的结构性候选。

## Consequences

- 收益：新装与所有升级后的老装都不再产生 `local`；多租户中转不会因默认值撞车。
- 代价：**所有旧装已配对手机要重新扫码**；旧中转令牌失效，`required` 模式要重签。
- 中转配置里仍绑在 `local` 上的旧令牌按**墓碑**处理：保留记录供管理台吊销/删除，但不进
  路由与认证索引，也不阻止启动（两条 `local` 不再触发唯一性冲突）。连接器端不会再使用它们。
- 证据：`connector/tests/connector-id.test.ts`（`local` 必迁移、新装随机、已是随机值不动）；
  `index.ts` 的迁移分支清 `clearRelayToken`。
