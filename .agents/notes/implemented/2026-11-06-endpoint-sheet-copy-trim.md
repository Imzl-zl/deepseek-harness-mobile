# 动作行不再挂解释句：设置页与端点弹框的文案收口

- 日期：2026-11-06
- 状态：implemented
- 触发：真机反馈（原话大意）——「这个弹框，我是看不懂这个功能吗？给我整这些解释？不 low 吗？」

## Problem

端点弹框的每个动作下面都挂一句解释：

- 「现在用这条连」→「会断开当前连接，只试这一条」
- 「删除这个端点」→「删掉后连接器再报也不会加回来，可在「已删除的端点」里恢复」/「手填的地址，删了就没了」

而这些**后果在别处已经说过**：删除有确认框（里面写了恢复路径），"现在用这条连"本身就表示立刻切换。
一句话既复述动作、又抢在用户动手前解释功能 —— 读起来像产品不信任用户。

## 判据（先例已在仓库里）

`lib/ui/host_picker_sheet.dart:53` 的注释写着：

> 只留**后果**（会断开当前那台）；"界面只显示新的那台"是它能自己看见的。

据此定三条：

1. **动作行只写动作**；不写复述动作、不写功能说明。
2. **只写用户看不见的后果**，且放在"真动手那一刻"（确认框/单条提示），不常驻在动作行上。
3. **状态与数据可以留**：`当前连接`、`已经在用这一条`、`提供商默认`、URL、百分比、宿主给的 description。

## 改动清单

| 位置 | 原文案 | 处理 |
|---|---|---|
| 端点弹框 · 现在用这条连 | `会断开当前连接，只试这一条` | 删（保留 `已经在用这一条` 状态） |
| 端点弹框 · 删除这个端点 | `删掉后连接器再报也不会加回来，可在「已删除的端点」里恢复` / `手填的地址，删了就没了` | 删（后果在确认框里原本就有） |
| 已删除端点行 | `点一下恢复` | 删（行本身可点；测试改成点整行） |
| 壁纸 · 去掉背景 | `回到纯色底` | 删（动作名已说明） |
| 壁纸 · 从相册选一张 | `会另存一份到 App 私有目录，不引用相册原图` | 收短为 `另存到 App 私有目录`（保留事实，去掉解释） |
| 添加端点 · 内置中转 | `开箱即用，不用填` | 删（地址在行上、默认选中） |
| 添加端点 · 自定义 | `自己部署的中转，或连别人家的` | 收短为 `自建或别人的中转` |
| 模型组注脚 | `提供商与密钥在电脑上改（DSH 的模型设置页）。` | 收短为 `提供商与密钥在电脑上改。` |
| 首选 toast | `已设为首选，下次自动连接时优先` | 收短为 `已设为首选` |

## 保留（并说明理由）

- `切换会立刻断开当前那台。`（host 选择 sheet）：唯一的"看不见的后果"，且只在真正切换时出现。
- 删除确认框里的恢复路径：动手那一刻才显示，属于"后果"而不是"常驻解释"。
- `已删除 N 条端点 · 点这里恢复`：这一行没有箭头/图标，去掉"点这里"就退化成一条静态注脚，属于可点性提示而非功能解释。
- `按这里的顺序自动拨，拨不通顺延；点一行设为首选。`：顺序=回落顺序不是自明的。
- 状态类（`当前连接` / `已经在用这一条` / `提供商默认`）与数据类（URL、百分比、宿主 description）。

## 代价

- 「现在用这条连」不再提示会断开当前连接；若之后真出现"不知道会断开"的反馈，应做成**条件提示**（仅当当前已连到另一条时显示一句），而不是恢复常驻句。
- 「删除这个端点」的恢复路径只在确认框里出现（原本也在），sheet 上不再预告。
