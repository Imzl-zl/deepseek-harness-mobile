# Agent Note: 底部这一条不涂底色 —— 让壁纸透上来，dock 自己浮

Status: implemented

## Problem

2026-10-20 为了盖掉一条 `sidebar` 灰带，把**底部包裹层**与 `DshComposer` 的 band 都涂成
`bgBase`（`2026-10-20-empty-state-and-bottom-strip.md`、`2026-10-20-composer-elevation-soft.md`）。

那时手机上还没有壁纸。2026-10-31 加了「壁纸 + 透明度」（`subsystems/appearance-wallpaper.md`）
之后，这条"页面色"就变成**一整块整宽的实色面板**，从会话区一直盖到屏幕底 —— 壁纸在会话区
看得见、一进底部就断掉。真机 2026-11-04 用户原话：

> 这个是悬浮的吧？你这个背景都上来了看着不是很好看了……做成那种悬浮的样式，
> 不要一大块白色面板。

同一轮还报了一条对齐问题：**点「编辑目标」时字和图标不在一条线上**（`_editRow` 用
`CrossAxisAlignment.end` 照抄了 DSH `.editBar` 的 `align-items: flex-end`，那是给多行正文用的；
这一格是单行）。

## Decision

**底部这一块不涂任何底色**：`chat_page.dart` 的包裹层与 `dsh_composer.dart` 的 band 都去掉
`color`。浮起来的是里面每一条 dock 自己的表面：

| 元件 | 表面 |
|---|---|
| 输入卡 | `c.composer` + `elevation-soft`；表面半透明时再挂 `DshGlass` |
| 目标条 | `c.menu` + `elevation-panel`（`subsystems/goal-bar.md` §1） |
| 排队条 | `c.layer1` + 描边 |
| 统计条 | `layer1` 药丸 |

判据一句话：**底部包裹层只负责排布与底部安全区**（`MediaQuery.padding.bottom + 6`），
不承担"底色"这个职责。灰带随底色一起消失 —— 2026-10-20 要盖的那条缝也就不存在了。

目标条的编辑行改成 `CrossAxisAlignment.center`（单行），并去掉图标那个 `bottom: 4` 的 Padding。

## Alternatives considered

1. 保留 `bgBase`，**只在有壁纸时**改透明
   - 最强的理由：没有壁纸时行为完全不变，零风险。
   - 为何被否：多出一条渲染分支，而没有壁纸时"透明"与"涂 `bgBase`"看到的**完全一样**
     （同一块底）—— 分支不产生任何可见差异，只多一处要解释的东西。
2. 保留一条**渐变**（底部透明，向上渐隐回 `bgBase`）
   - 最强的理由：内容从 dock 后面滚过时不会有硬切边。
   - 为何被否：dock 不在内容之上（它在 `Column` 里另起一行），没有"滚过去"这回事；
     渐变只会让壁纸在底部被糊掉一段，正是用户说的"背景都上来了"。
3. 把 dock 做成 `Stack` 浮在列表之上（真正的 overlay）
   - 最强的理由：最"悬浮"，滚动时内容从卡片后穿过去。
   - 为何被否：要重算列表底部 padding、接管 safe-area、处理"最后一条被卡片盖住"；
     而这次的诉求是"不要一大块白色面板"，不是"要穿过去"。等真有滚动穿透的需求再说。
4. 让输入卡在 100% 不透明时也强制毛玻璃
   - 最强的理由：与壁纸更融合。
   - 为何被否：透明度 < 100% 时 `DshGlass` 已经挂上了；100% 时强制模糊等于绕过用户设的
     "表面实心"（`appearance-wallpaper.md` §边界）。

## Consequences

- 收益：壁纸一直铺到屏幕底；底部不再是一条整宽面板，输入卡 / 目标条 / 排队条 / 统计药丸
  各自浮起来。编辑行的图标与文字同一条中线（真机 2026-11-04 复验）。
- 代价：**没有壁纸时**底部的层次只剩卡片阴影 —— 之前靠"面板 vs 卡片"的底色差。深色主题下
  这条差异最弱（柔光几乎不可见，只剩 `elevation` 的发丝描边）。
- 代价：`2026-10-20` 那两篇里"外层也改 `bgBase`"的结论**部分失效**。两篇的其余结论
  （`elevation-soft` 的三层阴影、顶栏改色）仍然生效，所以按"不得改写历史"的规矩，
  在文首加一行指向本篇，**没有**整篇移入 `archived/` —— 移进去会读成"整条决定作废"，
  而事实不是（这是**部分**取代）。
