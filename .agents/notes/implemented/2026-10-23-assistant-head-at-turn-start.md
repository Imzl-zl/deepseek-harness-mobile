# Agent Note: 「助手」头在轮次开头，不在中途

Status: implemented

## Problem

用户 2026-10-23 看真机截图后问：「助手不应该是开始的时候显示吗？怎么你这个中间显示？
不是一开始显示然后到输出完毕……我感觉就是有点不对，就是它一个在输出干嘛分这么多段？」

前一轮（`2026-10-23-one-assistant-head-per-turn.md`）把"每步一个头"收敛成"一轮一个头"，
但**头的位置**还钉在最终回答那条消息上。于是一个 60 步的轮次，头像出现在屏幕**最下面那一段**
（回答上方），而过程（思考 / 工具卡）在它上面 —— 读起来像"先有一堆工具，然后另一个人出来说话"。

## Decision

1. 头由**轮组**画：一轮里第一条"助手侧"条目（`ReasoningItem` / `ToolCallItem` /
   `ModelRetryItem` / `MessageItem(assistant)`）上方画一次
   （`model/turn_groups.dart` 的 `assistantHeadItemIds`）。
2. **按折叠后仍然可见的条目算**：收起一轮时被藏掉的条目不能是头像落点，
   否则头跟着过程一起消失（折叠后整轮没有助手段）。
3. **命令卡与压缩卡不拿头**：斜杠命令是用户发起、压缩是系统行为，主语不是助手；
   它们仍然是"过程"（随轮组收起）。
4. 消息自身不再画头（`AssistantTurn.showHead` 恒 false 由组头接管），
   流式尾条目 `_LiveTurn` 只在**本轮还没有任何助手侧条目**时自己带头。

## Alternatives considered

1. **在投影层造一条"轮头"条目**
   - 最强理由：渲染层零改动，列表里天然多一行。
   - 为何被否：投影层不该知道"哪里画头像"这种布局；而且这条虚拟条目会进条目表、
     被计数、被持久化推断，等于给"条目"这个词加语义负担。
2. **头仍挂在回答上，只把过程挪到回答下面**
   - 最强理由：不改头的位置。
   - 为何被否：过程与结论的先后是**事件顺序**（思考 → 工具 → 回答），倒过来是撒谎；
     而且 DSH 与主流都是"块头在最上"。
3. **只画一个头但不折叠时也保持在同一行位置（sticky 头）**
   - 最强理由：长轮次里滚动时始终能看到"这是助手在说"。
   - 为何被否：手机屏小，粘性头会吃掉正文高度；且 Flutter 侧要自己算滚动偏移，
     比"组内第一个条目带头"复杂一个量级。

## Consequences

- 收益：一轮读起来是「助手（头）→ 思考 / 工具 → 回答 → 收口行」；
  收起后是「助手（头）→ 回答 → 收口行」。真机 `shots-2026-10-22/p1/p2` 是上一版，
  本轮的头位置在 `r1-head-at-top.png`（收起）/ `r2-head-at-top-expanded.png`（展开）。
- 代价：
  - 头像与它下方的内容之间多了一个 `Column` 包裹层（每轮一个）；
  - 头会出现在**工具卡上方**，所以"这一轮有过几次工具"这个信息由收口行的统计承担
    （头只表示"这里是助手的一段"）。
- 顺带修掉的三处（审查时发现）：
  1. **同一轮可能画两个头**：`assistantHeadItemIds` 原先按"轮号变化"换段，
     `turn/end` 之后那些没有轮号的记账条目（`request/*`）会把段打断 ⇒
     思考与回答各拿一个头。改成"只按非空轮号变化换段"。
  2. **`next-input` 档的"最新一轮"判据偏了**：原先取"最后一个可折的轮"，
     于是用户发出下一句、新一轮还没收口时，上一轮仍保持展开。改成"它是不是最后一组"。
  3. **两处死代码**：`TurnProcessRow.running`（组头只在收口后出现，没人传 `true`）与
     `AssistantTurn.modelName` / `AssistantHead.modelName`（没有任何调用方传）
     一并删掉，`running-cues.md` 与本节同批更新。
- 判据：
  - 纯函数（`app/test/turn_groups_test.dart`，17 条）：头落在第一条助手侧条目、
    折叠后按可见条目算、命令卡/压缩卡不拿头、夹一条无轮号记账事件也只画一个头、
    只有用户消息的组不拿头。
  - 页面（`app/test/turn_group_collapse_test.dart`，4 条）：收起/展开都只有一个「助手」，
    且 `getTopLeft(助手).dy < getTopLeft(思考过程/回答).dy`（位置断言，不只是存在性）。
  - 门禁：flutter **1106** / boundary **352** / analyze+format 0。
