# Agent Note: 原型子智能体面板 = 落地端的**目录树**（不是另一份演示）

Status: implemented（2026-10-23）。

## 起因

2026-10-21 对齐落地端时有意留了一处差异（`docs/subsystems/subagent-page.md` §6 第 3 条、
`memory.md` 待办 8）：App 已经是「直接子级 + 展开懒加载 + 三态 + token + 详情行」，
原型 `renderSubs` 还是 `SUBS` 三条平铺演示行 —— 「进行中 N · 已结束 M」分组 + 可折叠的 `out` 行。

两边的形态差在**结构**上，不在配色上：原型没有 disclosure、没有三态、没有 token、
没有第二行指标。而 `mock/proto/` 是本仓的**交互基线**（根 `AGENTS.md` §2），
基线里没有的形态，下一个会话读原型时就会得出"手机上没有这个面板"的结论；
"改基线要同步改落地端、不允许两边各自漂移"是根 `AGENTS.md` 的常驻军规。

这一轮**不新增 App 行为**（App 领先），只让原型追平，并补一个能跑通的脚本把结构钉住。

## DSH 的形状（判据出处）

- 一层的目录**只含直接子级**（`packages/subagent/subagent/src/catalog.ts:111-131`），
  孙级要**展开才再读一次那一层**（`SubagentHeaderLineage.tsx:570-577` 的 `toggleBranch` → `refreshProjection`）。
- 三态：`loading` + 空 entries ⇒ 加载中（`:212`）；`error` ⇒ 失败 + 重试（`:222-234`）；
  `ready` + 空 ⇒ **已知空叶**（`:196-198` 的 `isKnownLeaf`，唯一敢说"它没有下级"的判据）。
- 行：`:235-373`。活动点 `:336-338`、第二行 `:257-259`、token `:66-74,260`、时长 `:77-91`、
  disclosure `:242,325-334`；文案 `ui-subagent/src/client/locales.ts:22-39`。
- 触屏四条偏离见 `docs/subsystems/subagent-page.md` §3.1（行尾 44×44 / 不预留槽 /
  右列只放 token / 缩进 12 只画竖线）。

## 决定

1. **数据改成"按父会话分层的直接子级表"**：`SUBS` 从数组变成 `{ sid: {state, entries} }`，
   `entries` 是 catalog 行 `{id, createdAt, mode, label}`。表里没有 = 已读到空；
   `loading` = 还没读过；`error` = 那一层读不回来。
   演示数据覆盖六件：可续聊（在跑）/ 一次性 / external / 目录读失败 / 已知空叶 /
   可展开的孙级（它自己再带一个曾孙，用来验"收起连带收整枝"）。
2. **渲染递归一层一目录**：`subsLevelHtml(sid, ancestors, isRoot)`，展开集合 `subExpanded`；
   `readSubs(sid)` 模拟电脑侧答复（520ms，**保留旧行**所以不闪空）。
   `ancestors` 截断环 —— 畸形投影里的环会让递归打穿栈（不可捕获的 `StackOverflowError`，整页白屏）。
3. **两套手势**：行尾 `<button class="sub-exp">`（44×44）= 只展开；整行 = 进入
   （`enterSubagent` → 收起抽屉 + 一句提示）。external 行没有 `data-sub-enter`、`aria-disabled`。
4. **面板 root = 当前会话**：抽屉里点会话行就换 root（行上加了 `data-sid`）。
   「没有子智能体。」这一态只能从"根层读到空"出现，而三态里的第三态在原型里必须到得了 ——
   这条真实路径（切会话）比另做一个演示开关诚实。
5. **活动点与转圈统一到一枚**：实心态照 DSH 的 `10px 槽 + 6px 核`
   （`StateDot.module.css:1-15`），转圈用图标集的 `loading`（`.spin-arc`，1.5s 匀速）。
   任务面板原本手绘的环 + 弧（`.sdot-spin`）一并删掉 —— 同一个语义只留一个实现。
6. **抬头只有标题**：App 的 `SideHeader(title: '子智能体')` 没有副标题
   （`app/lib/ui/chat_page.dart:1337`），原型照同一条，不再摆"N 个运行中"。
7. **新脚本 `mock/proto/tools/verify-subs.mjs`**：41 项，口径与其它 `verify-*` 一致
   （`CDP_URL` + `NO_PROXY`、失败打印 JSON、项数是脚本里数出来的）。

## 代价与边界

- **"进入"在原型里没有子会话内容**：可见后果只有"抽屉收起 + 一句提示"。
  真实链路（换主对话区、`subagent.prompt`）不在原型的能力范围，所以不假装。
- **root 靠抽屉行切换**：原型没有"会话内容"这回事，点抽屉行原本只离开 blank 页；
  现在多写一个 `curSid`。代价是"面板 root"与"主对话区"在原型里不是同一个真值
  （真机上它们由同一个 `sid` 决定）—— 但面板内容与 root 严格对应，不制造假象。
- **重试永远失败**：`sub-broken` 那一层在演示数据里就是读不回来。代价是"重试看起来没用"，
  收益是错误态与"重试 = 重读这一层"（不是重开抽屉）能被脚本钉住。
- **没做"当前行加粗"**：抽屉里的树 root = 当前会话，当前行不在树里（App 的抽屉同样不传
  `currentSid`；加粗只发生在切换浮层）。原型没有切换浮层，故不做 —— 不做就不会有假形态。
- **没做切换浮层与只读输入框**：那是 `subagent-page.md` §4/§5 的另一块面。
- **行字号 12 / 11**：`docs/subsystems/subagent-page.md` §3.1 原先写 12.5 / 11，
  那是 2026-10-22 字号批次把半点字号收敛成整数**之前**的值（App 的 `_SubagentRow` 现在是 12）。
  文档已按 App 改正。

## 被否掉的替代

- **只改演示数据、保留平铺行**
  - 最强理由：不动渲染代码，改完立刻能"看到更多子代理"。
  - 为何被否：平铺行没有 disclosure、没有三态、没有第二行、没有 token —— 那正是要同步的四样；
    留着它等于承认基线里可以有两个形态。
- **给面板加一个"演示状态"开关**（有子级 / 空目录 / 读失败）
  - 最强理由：三态都能一键演示，不依赖任何真实路径。
  - 为何被否：那是**产品上没有的控件**；基线上多一个只存在于原型的按钮，比缺一条演示路径更坏。
    空态用"点抽屉会话行换 root"这条真实路径拿到。
- **进入子会话时把面板 root 换成那个子级**
  - 最强理由：与"进入 = 当前会话变成它"同一条，空态也能顺着点进去拿到。
  - 为何被否：原型没有子会话内容，root 一变就没有回头路（没有 `←`、没有顶栏切换）——
    用户会被困在一个只能重开页面的面板里。等原型有子会话内容（§4/§5）再谈。
- **只给子智能体行换新点，任务面板照旧**
  - 最强理由：改动面最小，任务面板的观感不动。
  - 为何被否：同一个抽屉里两枚"在跑"信号（手绘环 vs `loading` 弧）、两种点径（10px 实心 vs
    6px 核）就是两份真值；App 只有一枚 `DshStateDot`。一次改完反而少一处要记的差异。
